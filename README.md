# Mr. English Academy

**Create a world-class, premium educational web application** for an English teacher named **"Mr English – Mr. Mostafa Awad"**. The website should feel as polished, elegant, and premium as Apple's product pages while maintaining a modern educational identity. Every animation, transition, spacing, typography, and interaction should feel smooth, luxurious, and highly professional.

---

# Overall Design Philosophy

Design Language:

* Apple-inspired minimalism
* Premium educational platform
* Modern glassmorphism mixed with soft neumorphism
* Extremely smooth animations (60 FPS)
* Beautiful gradients
* Rounded corners
* Soft shadows
* Excellent spacing
* Responsive on Desktop, Tablet, and Mobile
* Professional micro-interactions everywhere
* Dark Mode & Light Mode with automatic system detection
* Accessibility friendly

Color Palette:

* White
* Soft Blue

* Premium Gray
* Accent Blue

Typography:

* Elegant display font for headings

* Beautiful letter spacing

# Level System

Initially:

Only Level 1 is unlocked.

Every level contains:

Default:
7 questions

However,

The teacher can increase or decrease the number of questions through the admin dashboard.

A student passes a level only if they answer **more than half of the questions correctly**.

If they fail:

Show a beautiful animated message:

"Unfortunately, you need more than 50% to pass this level."

Display:

Retry button

Review mistakes button

Return Home button
